01

一句话看懂

先不要被文件名吓到，把它想成一条正在修建的舆情加工流水线。

ReadTrace 的目标：从小红书取得品牌相关帖子和评论，保存可追溯的原始证据，再分析负面原因，最终给领导、策划和运营查看。当前仓库完成的是流水线前半段的技术底座。
02

现在有什么，还缺什么

“PRD 写了”不等于“代码已经有了”。这两类内容必须分开理解。

已实现

可以运行的底层能力

  • 低频打开小红书并验证搜索、详情、评论的数据取得能力
  • 识别登录、验证码和访问频繁等页面状态，并停止危险操作
  • 对帖子、评论和原始快照进行脱敏、去重与结构化整理
  • 连接 MySQL 8.0，执行数据库健康检查和只向前迁移
  • 保存采集任务、帖子、评论、互动快照、品牌命中关系
  • 提供租约锁和游标，避免多个任务重复采集或互相踩踏
  • 使用自动化测试验证配置、迁移、持久化和协调逻辑
尚未实现

完整产品仍需建设

  • 正式网页前端、后台接口和管理员登录
  • 每小时自动调度以及可长期运行的正式采集服务
  • DeepSeek V4 情感、品类、问题类型与原因主题分析
  • 舆情总览、内容明细、人工修正和数据状态页面
  • Excel 导出、分类配置与业务筛选
  • 云服务器部署、监控告警与完整生产运维
03

用了什么技术

技术只是工具。下面同时说明“它是什么”和“在本项目中做什么”。

RUNTIME

Node.js ≥ 20

让 JavaScript/TypeScript 可以不依赖网页，在电脑或服务器上运行。它是整个项目的运行底座。

LANGUAGE

TypeScript 5.8

带类型检查的 JavaScript。这里开启了严格模式，尽量让字段写错、空值遗漏等问题在运行前暴露。

BROWSER

Playwright 1.54

自动控制 Chromium 浏览器，用来低频验证小红书搜索页、详情页和首批评论的数据链路。

DATABASE

MySQL 8.0

长期保存采集任务、帖子、评论和快照。代码通过 mysql2 连接；当前项目不是 PostgreSQL。

CONFIG

dotenv

从本地环境文件读取数据库配置。真实密码放在被 Git 忽略的 .env.local，不会提交到仓库。

QUALITY

tsc + node:test

TypeScript 编译器负责类型检查，Node 自带测试框架负责自动验证关键逻辑，没有额外测试框架。

仓库目录地图

先看鸟瞰图，再逐个文件夹解释。

ReadTrace/
├─ src/                 正式源代码
│  ├─ xhs-probe/       小红书数据能力探针
│  └─ db/              MySQL 连接、迁移、保存与任务协调
├─ migrations/          数据库结构变更脚本
├─ tests/               自动化测试
├─ docs/                说明、验收标准、交接资料与工作日志
├─ tasks/               产品需求文档 PRD
├─ artifacts/           探针运行结果，本地生成、不提交
├─ .local/              浏览器登录状态和运行锁，本地私密、不提交
├─ node_modules/        安装的第三方代码，可重新生成
├─ .test-dist/          测试编译产物，可重新生成
├─ package.json          依赖与常用命令清单
├─ tsconfig*.json        TypeScript 编译规则
├─ .env.example          数据库配置示例，不含真实秘密
├─ .gitignore            规定哪些本地文件不能提交
└─ AGENTS.md             本项目协作与产品边界
src/
产品代码的家。程序真正执行的逻辑都在这里。目前分成采集探针和数据库两个领域，边界比较清楚。
migrations/
数据库的装修图纸。0001_collection_schema.sql 创建 12 张业务表并初始化小红书数据来源。以后改表应新增编号文件，不回头篡改历史版本。
tests/
自动检查清单。模拟各种输入和数据库行为，验证代码修改后没有破坏已有能力。文件名与被测模块基本对应。
docs/
工程说明与过程档案。database.md 和 xhs-probe.md 是使用说明；pm-*.md 是验收标准；handoff/ 放交接资料；worklogs/ 记录每次非平凡工作的过程。
tasks/
产品要做什么。当前只有第一版 PRD，描述目标用户、页面、分析维度、验收条件和非功能要求。它是目标地图，不代表其中所有功能已经完成。
artifacts/
探针的本地输出。每次运行产生 report.json、posts.json、comments.json 和脱敏后的 raw/ 快照。被 Git 忽略。
.local/
本机私密运行状态。包含小红书浏览器登录资料和防止重复运行的锁文件。不能复制、外传或提交。
node_modules/
第三方工具箱。npm install 自动下载，体积较大，不是团队手写代码，也不会提交。
06

源代码逐层说明

点击每组可以展开。这里覆盖仓库内所有手写源代码文件。

src/xhs-probe/ — 小红书探针
cli.ts
总指挥：读取命令参数、打开浏览器、等待人工登录、搜索帖子、访问详情、收集响应并写出报告。
extract.ts
翻译员：从页面状态、JSON-LD 和接口响应中寻找字段，统一帖子与评论格式，并检查相关性和时间冲突。
sanitize.ts
安检员：遮盖 Cookie、Token、手机号、敏感查询参数和错误信息中的秘密。
page-signals.ts
路况识别：判断页面是否要求登录、验证码，或提示访问频繁。
url.ts
地址解析：从小红书链接中取得帖子 ID，并生成不带临时令牌的标准来源链接。
types.ts
数据字典：定义帖子、评论、采集错误和运行报告应该包含哪些字段。
src/db/ — 数据库公共底座与命令
config.ts
读取并严格校验 MySQL 地址、端口、账号、数据库、SSL 和连接池上限。
pool.ts
创建数据库连接池，并把每个连接的时间语义统一为 UTC。
errors.ts
把底层 MySQL 报错转换成安全、稳定的错误类型，避免泄露连接信息。
migrations.ts
发现 SQL 迁移、校验校验和、加数据库锁并依次执行，只允许向前升级。
health.ts
db:health 命令入口，只读检查版本、SSL、时区和连接池。
migrate.ts
db:migrate 命令入口，执行待应用的数据库迁移。
status.ts
db:status 命令入口，只读显示迁移状态和业务表是否齐全。
integration.ts
真实数据库验收脚本：临时写入一组测试数据，检查保存、幂等、回滚、锁和游标，再清理自己的测试数据。
src/db/persistence/ — 把采集结果可靠地保存下来
service.ts
业务编排层：先验证任务，再用事务一次保存一批帖子、评论、快照和品牌命中关系。
repository.ts
具体 SQL 操作：新增或更新帖子评论、写互动快照和脱敏原始字段。
task-repository.ts
采集任务的创建与状态变化，控制哪些品牌可以启动任务。
mapping.ts
把探针格式转换成数据库格式，并阻止关键字段缺失的数据入库。
redaction.ts
入库前再次脱敏并稳定序列化原始快照。
errors.ts
定义持久化层自己的安全错误。
types.ts
定义任务、批次、帖子、评论和返回结果的数据形状。
index.ts
统一出口，让其他模块从一个位置引用持久化能力。
src/db/coordination/ — 多任务之间不要互相踩踏
locks.ts
品牌租约锁：同一时间只让一个合格任务采集同一品牌，并支持续租和释放。
cursors.ts
采集游标：记录采到哪里，只允许合法任务把进度向前推进。
types.ts
协调模块共用的数据类型、ID 比较和输入校验。
index.ts
协调能力的统一出口。

常用命令怎么理解

在项目根目录的 PowerShell 中运行。真实数据库配置应只放在 .env.local。

命令作用会不会改数据
npm install按照 package-lock.json 安装第三方依赖只生成 node_modules
npm run typecheck检查 TypeScript 类型是否正确不会
npm test编译并运行自动化测试只生成测试临时产物
npm run probe:xhs -- --keyword Leader打开浏览器并执行一次低频小红书探针写入本地 artifacts，不连接 MySQL
npm run db:health确认 MySQL 能连接且版本、SSL、时区正确只读
npm run db:status查看迁移版本和表是否齐全只读
npm run db:migrate应用尚未执行的 SQL 迁移会改变数据库结构
npm run db:integration在真实数据库运行持久化验收临时写入并清理测试数据
08

小白最容易误解的四件事

这还不是一个网站

仓库里没有 React、Vue 或正式 HTML 前端，也没有 HTTP API 服务。当前主要是命令行工具和数据库模块。

PRD 不等于成品

tasks/ 写的是最终想要的系统；判断是否已经实现，要以 src/ 和可运行命令为准。

探针不等于正式采集器

它受到 20 条搜索结果、3 篇详情和至少 2 秒间隔的硬限制，主要用于验证页面数据是否可取得。

数据表是地基

数据库已经为品牌、任务、帖子、评论、快照、游标和锁搭好结构，但模型分析相关表与业务页面仍未建设。
