# 内容明细筛选区固定

## 目标

移除内容明细页重复的页面标题块，让帖子库、评论库和筛选条件更靠近顶部，并在浏览列表时保持筛选区可见。

## 实现

- 删除内容明细页的页面标题块及其不可用的导出操作。
- 加载、错误和正常状态统一把现有筛选区固定在顶部栏下方。
- 模拟模式下，筛选区同时避开顶部栏和模拟数据提示条。
- 帖子库、评论库、筛选字段和列表结构保持不变。

## 验证

- Web生产构建通过。
- 浏览器确认页面标题块数量为0，滚动700像素后筛选区固定在顶部栏和模拟提示条下方，控制台没有错误。
- 全量测试被工作区中同时进行的“数据采集控制台”后端改动阻断：MySQL仓储尚未实现新接口。本次提交不包含这些并行改动。
