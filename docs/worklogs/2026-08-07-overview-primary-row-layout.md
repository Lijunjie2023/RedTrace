# 首页主三栏空间优化

## 目标

- 问题热榜按照证据数量降序展示，最多显示10条。
- 桌面端的负面问题变化、问题热榜和代表性原话保持等高。
- 趋势图和指标带填满左侧面板，避免面板底部出现大块空白。
- 热榜与代表性原话在面板内部滚动，避免内容数量改变整行高度。
- 调整热榜排名、问题名称和统计列的间距，保证表头横向展示。

## 实现

- 新增基于视口高度的 `--overview-primary-panel-height`，桌面端三栏共享同一高度。
- 在1024px至1439px的中等桌面宽度下，将三栏调整为4/5/3列，给问题热榜留出完整展示五项数据列的空间；1440px及以上保持6/3/3列。
- 小于1024px时取消固定高度和内部滚动，使单栏布局恢复自然高度。
- 趋势面板改为纵向弹性布局，图表占用剩余空间，指标带固定在底部。
- 为代表性原话增加独立滚动内容区；问题热榜列表使用面板内部纵向滚动。
- 热榜表头与数据行共用同一列模板，并增加排名与问题名称之间的间距。
- 热榜列表不再固定预留滚动条槽位，列网格按照滚动区域的实际内容宽度计算，避免桌面端出现几像素的横向溢出。
- 热榜数据行取消显式的百分比宽度，改为块级自动宽度，使其在纵向滚动条出现后严格贴合滚动口；表头继续占满面板宽度。

## 验证范围

- 首页主三栏样式契约测试。
- Web类型检查与生产构建。
- Git差异格式检查。
