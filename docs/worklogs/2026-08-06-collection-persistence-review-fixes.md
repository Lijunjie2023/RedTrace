# 采集持久化复审修复记录

日期：2026-08-06

## 修复内容

- 扩大小红书敏感信息脱敏范围，覆盖对象键、URL 查询参数和普通文本请求头中的 `a1`、`x-s`、`x-t`、`authorization` 与 `cookie`，同时使用精确键名判断，避免误删普通 ID 字段。
- 复审后补回 `web_session`、`auth_token`、`access_token`、`refresh_token`、`client_secret`、`api_key`、`session_key` 等通用凭据的大小写及分隔符变体；匹配仍基于规范化后的完整键名，不按 `session` 或 `token` 子串模糊删除。
- 采集任务只允许从 `queued` 进入 `running`，已运行任务不能再次启动；失败任务仍通过新建重试任务恢复。
- 单篇持久化发生异常时尝试回滚；回滚失败则销毁连接并禁止归还连接池，正常回滚后才释放连接。
- 评论幂等更新不再改写所属帖子。更新后校验评论仍属于当前帖子，跨帖子冲突会以固定错误终止并由事务回滚。
- 父评论查询和历史父子关系补齐都增加帖子范围，避免同一数据源内不同帖子的评论发生串联。
