## 安全措施

- Token只从本机`.env.local`的`JUSTONEAPI_TOKEN`读取。
- 只允许访问`https://api.justoneapi.com`。
- 输出前递归删除Token、Cookie、Authorization、`x-s`、`x-t`和`a1`等敏感字段，并删除URL中的对应查询参数。
- 控制台和报告只记录接口路径，不记录带Token的完整请求URL。

- `npm test`：通过，93项通过、1项因Windows符号链接权限跳过。
- `npm run typecheck`：通过。
- Token已通过本机`.env.local`提供，测试产物中没有检出Token原值。
