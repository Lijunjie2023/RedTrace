# 首页驾驶舱与数据管理前端改造

日期：2026-08-06

## 本次范围

- 首页采用趋势、问题热榜、代表性原话、品类对比、情感构成和数据质量的驾驶舱布局。
- 品牌筛选改为可搜索多选，品牌编号以逗号分隔写入 `brandIds`。
- 产品品类从分类配置接口读取，品类编号以逗号分隔写入 `categoryIds`。
- 点击品类卡片会同步顶部筛选，并刷新整个首页。
- 品类卡片始终展示当前日期与品牌范围内的完整候选分布，选择品类后仍可直接切换或叠加其他品类。
- 点击问题热榜只刷新右侧相关证据，`topicId` 保留在 URL 中，日期、品牌和品类条件继续生效。
- 主导航暂时隐藏问题分析与内容明细，但原路由和证据详情深链继续保留。
- 新增数据管理页面，展示采集总量、AI分类进度、分析运行及失败数量、人工修正数量和最近分析时间。

## 数据口径

- 页面仅使用接口返回的真实数据。
- 缺少分品类负面占比、分品类主要问题和同期变化时，显示“待统计”，不使用设计示意数字。
- 评论缺少可靠发布时间时，前端不推算发布时间；后端日期筛选按照所属帖子发布时间处理。
- 问题证据保留证据详情和小红书原文入口。
- 修改品牌或品类时会清除旧的问题选择，避免右侧残留不属于新筛选范围的证据。
- 趋势钻取同时覆盖帖子和评论，不会默认收窄为帖子。
- 数据总量为零时明确显示“尚未采集内容”和0%分类进度，并提供监控设置入口。
- 数据管理按照内容条数展示正在分析和分析失败的数量，不将其误称为任务数量。
- 对内容不存在和筛选参数错误分别提供准确提示，不再统一显示网络故障。
