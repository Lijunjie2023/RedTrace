# 驾驶舱响应式连续性修复

日期：2026-08-06

## 修复内容

- 移除正文区域的整体最大宽度，使页面始终占满侧栏之外的可用视口。
- 侧栏、顶部栏和正文共用连续、单调变化的 `clamp()` 宽度，消除1439到1440像素之间正文反向缩窄的问题。
- 侧栏使用容器查询分成图标、导航文字和完整品牌信息三个显示阶段；显示阈值跟随根字号变化，中等宽度会显示导航文字，不会形成宽大的空侧栏。
- 容器查询按照侧栏内容区宽度使用8、9、10rem三个可达阈值；1439到1440像素切换内边距后，已经显示的副标题不会反向隐藏。
- 首页在1024像素及以上保持约2:1:1的三栏布局，1023像素及以下改为单栏。
- 品类卡片改为 `auto-fit` 与 `minmax` 弹性排布，中等宽度自动形成两列或三列，手机保持单列。
- 模拟模式在手机端隐藏次要说明，横幅保持可计算高度，不会因换行覆盖正文。
- 问题分析页面在1599像素及以下改为两列，证据区进入下一行，避免1440到1523像素范围发生裁切。
- 内容明细使用零最小宽度主列和弹性预览列，避免1024到1031像素发生页面级横向滚动。
- 趋势图在768到1320像素显示横向滚动提示，避免中等桌面宽度误判数据缺失。
- 品类卡片轨道设置合理上限，少量品类在超宽屏下不会被拉伸成超大卡片。
- 移除 `body` 的横向溢出隐藏，布局错误不会再被全局裁切掩盖。

## 静态检查覆盖

- 320、375：底部导航、模拟横幅、单列面板和品类单列。
- 768：紧凑侧栏、正文可用宽度、品类弹性列。
- 1024：首页三栏开始生效，面板以2:1:1比例共享可用宽度。
- 1199、1200、1366：三栏持续同一行，侧栏宽度连续增长，品类自动形成合理列数。
- 1440：侧栏切换完整导航时宽度不跳变，正文不会反向缩窄。
- 1920、2560：正文占满侧栏外视口，首页保持弹性三栏且不存在整体最大宽度。
- `/insights`：1440到1523像素采用两列加证据下一行，避免最小列宽挤出视口。
