# ReadTrace暗色舆情看板设计工作日志

## 任务

在不修改前端源代码的前提下，为现有ReadTrace五个主页面、登录页和内容详情页制定统一暗色生产界面方案。视觉方向参考用户提供的暗色舆情大屏。

## 扫描内容

- 项目`AGENTS.md`
- `ui-designer`与`frontend-design`skill
- 前端应用壳、公共组件、全部页面、全局样式和API客户端
- `packages/contracts/src/index.ts`数据合同
- 既有UI方案、三套原型及相关工作日志
- 用户提供的暗色参考图和当前线上错误页截图

## 关键判断

- 保留五项主导航与现有路由，不调整产品信息架构。
- 视觉改为炭黑底、分层灰面板、风险红主强调的暗色分析后台。
- 概览采用趋势、上升主题和高风险证据同屏的结构。
- 界面只展示现有合同可以支持的指标，不复制参考图中缺少真实数据来源的字段。
- `DATA_NOT_READY`需要与网络故障、依赖不可用和合同错误分开展示。
- 推荐先改应用壳与概览页，再让其余页面继承设计系统并逐页精修。
