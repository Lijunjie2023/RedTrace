# API 采集增加大家电行业相关性过滤

## 问题

JustOneAPI 搜索结果只按关键词命中过滤。“统帅”既是家电品牌词，也可能出现在动漫、角色和日常表达中，因此非大家电帖子会进入评论采集和数据库写入流程。

复现文本：帖子包含“小马塑、统帅、国王天角兽”等内容，但没有任何大家电品类语境。

## 处理原则

- 数据采集继续完全使用 JustOneAPI，不调用浏览器采集。
- 搜索关键词命中只用于生成候选帖子。
- 读取 API 帖子详情后，标题、正文和话题必须同时满足关键词命中与大家电品类语境，才允许继续采集评论和写入数据库。
- 不相关帖子直接跳过，不请求其评论，也不写入业务数据库。

## 验证

- 采集相关测试：20 项全部通过。
- 新增回归测试覆盖用户提供的“小马塑、统帅、国王天角兽”误收录文本，以及“统帅洗衣机”正常收录文本。
- `npm run build`：根项目、API、Web 和契约包构建通过。
- 完整测试：新增功能相关断言全部通过；另有 1 项既有导航数量断言失败，原因是并行提交 `1cd7f3d` 主动隐藏了关键词导航，但对应测试仍预期 6 项导航，与本次采集改动无关。
- 代码审查：过滤发生在 API 帖子详情解析后、评论 API 请求前；不相关内容不会请求评论，也不会进入持久化流程。
- 线上验收：部署后补充。
