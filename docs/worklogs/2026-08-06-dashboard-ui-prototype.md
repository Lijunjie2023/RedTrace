# ReadTrace 舆情总览 UI 原型工作日志

## 验证问题

ReadTrace 面向领导层、策划岗和运营岗时，舆情总览应该采用怎样的信息层级与视觉表达。

## 原型边界

- 单文件、只读、使用模拟数据，不连接小红书或 MySQL。
- 不属于正式产品代码，不代表前端技术选型。
- 通过 `?variant=A|B|C` 切换三套结构明显不同的界面。

## 三套方案

- A：领导决策总览。强调指标、趋势、高风险内容和问题排行，适合默认入口。
- B：舆情作战台。强调实时信号、风险队列和采集状态，适合运营值守。
- C：策划研究周报。强调结论、趋势解释和代表性用户原话，适合策划与汇报。
