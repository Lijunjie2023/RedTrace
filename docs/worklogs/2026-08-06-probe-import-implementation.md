# 小红书探针产物导入实现记录

日期：2026-08-06

## 目标

增加受控命令行入口，把已经生成的小红书探针产物导入现有MySQL采集持久化链路，为真实DeepSeek帖子和评论分类联调准备可追溯数据。

## 实现

- 新增`db:import-probe`命令，强制要求`--run-dir`和`--brand`。
- 导入目录经过真实路径校验，只接受工作区`artifacts/xhs-probe`下的目录；三个固定名称的JSON文件也分别校验真实路径和普通文件类型，阻止目录及文件级符号链接逃逸。
- 使用严格结构校验读取`posts.json`、`comments.json`和`report.json`，同时校验运行编号、去重后数量、帖子唯一性、评论唯一性及评论所属帖子。
- 帖子和评论来源链接只接受`https`协议下的`xiaohongshu.com`及其子域名，拒绝其他协议和域名。
- 幂等创建或复用小红书数据来源、指定品牌和同名别名搜索词，并为每次导入创建一个手动采集任务。
- 只导入已经判定相关且正文不为空的详情帖子；评论按`noteId`归属帖子。
- 复用`CollectionPersistenceService`保存帖子、评论、互动快照、脱敏原始字段快照和品牌命中关系，没有绕过业务持久化服务。
- 命令输出仅包含任务内部ID和数量汇总；错误只返回固定错误代码，不输出正文、作者、平台业务ID、链接或数据库连接信息。

## 边界

- 重复导入会创建新的采集任务和对应历史快照，但帖子、评论和品牌命中关系依靠现有唯一约束保持幂等。
- 本工作包不调用DeepSeek，也不读取或处理模型密钥。
- 测试由主控补充，本实现只执行类型检查和差异检查。
