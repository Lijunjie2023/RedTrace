# 小红书数据采集能力验证工作日志

日期：2026-08-06

## 验证目标

使用真实登录状态验证`Leader`相关帖子、详情、互动数据、评论和回复关系是否能够取得。本轮仅做低频只读验证。

## 已验证结果

- 未登录时可以读取公开推荐内容和搜索联想，但登录弹窗阻断完整搜索。
- 用户完成登录后，`Leader`搜索页可以正常打开。
- 搜索结果能够取得帖子平台ID、标题、作者、展示时间、互动摘要和带访问参数的链接。
- 搜索结果包含`Leader统帅电器`官方账号及Leader家电相关帖子。
- `Leader`同时表示英文语境中的管理者，搜索结果存在大量无关内容，需要结合`统帅、海尔`和产品品类词过滤。
- 已打开一篇Leader统帅三筒洗衣机负面帖子，并取得完整正文、作者、地区、话题、图片、帖子ID和互动数据。
- 已取得评论正文、评论ID、作者、展示时间、地区、点赞数和一级／二级回复关系。
- 样本帖页面显示22条评论，页面当前能读取多条一级评论和已展开回复。
- 页面JSON-LD提供的发布时间与页面展示时间存在冲突，原始状态中另有毫秒时间戳。后续必须保留时间来源并标记冲突，不能直接信任单一字段。

## 样本字段证据

- 帖子ID：能够从URL和页面原始状态取得。
- 评论ID：能够从评论节点ID取得。
- 父评论关系：二级回复与所属一级评论位于同一评论组，可以取得两者ID。
- 互动数据：能够取得点赞、收藏、评论和分享数量。
- 原始证据：能够保留帖子链接、正文、话题、图片链接和评论上下文。

## 当前限制

- 本轮证明了浏览器内真实数据可读取，尚未证明独立采集程序能够长期保持登录状态。
- 尚未验证评论完整翻页、图片文字识别、小时级持续运行和账号长期风险。
- 当前登录状态位于Codex内置浏览器，正式采集程序需要独立的本地持久化浏览器目录，由用户首次运行时完成登录。
- 不应记录或导出浏览器Cookie、Token和手机号等凭证。
