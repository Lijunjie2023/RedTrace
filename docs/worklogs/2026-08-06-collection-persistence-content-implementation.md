# 采集内容和任务持久化实现记录

日期：2026-08-06

## 实现范围

实现采集任务创建、开始、结束、失败与重试关联，以及帖子、评论、互动快照、脱敏原始快照和品牌命中的持久化服务。本工作包没有实现租约锁和游标推进，也没有连接正式数据库。

## 事务边界

每篇帖子使用独立事务。帖子、所属评论、互动快照、原始字段快照和品牌命中必须全部成功才提交；任一步失败都会回滚该篇的本次写入。此前已经成功提交的其他帖子不受影响，批处理最终按成功和失败数量标记为成功、部分成功或失败。

## 数据规则

- 帖子和评论依靠数据来源与平台ID完成幂等更新。
- 新一轮缺失字段使用`COALESCE`保留历史非空值。
- 评论先保存平台父评论ID，能够定位内部父评论时同步关联，并在一篇评论写入完成后补齐历史缺失关系。
- 互动快照通过任务与内容唯一键去重，缺失互动值保留为`null`。
- 原始字段必须经过现有脱敏器和JSON序列化，失败时抛出固定结构化错误，不保存快照或输出原文。
- 品牌命中由调用方提供品牌与搜索词，不在持久化层硬编码品牌。
