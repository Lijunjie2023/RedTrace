## 联调修复

- AC12游标更新由多表UPDATE改为单表CAS，并在`EXISTS`子查询中原子校验任务归属和状态，解决MySQL 8.0目标别名赋值和同名字段歧义。
- 当前npm不支持`workspace:*`协议，API共享契约依赖改用本地`file:`路径，与Web保持一致。
- 前后端采集任务路径统一为`collection-runs`，修正Web残留的`collectionTasks`旧路径。
- 采集任务列表保持`data`数组，分页及最后成功时间、连续失败次数、数据量异常统一放入`meta`。
- 正式管理员认证尚未实现，LIVE模式现在拒绝创建本地模拟会话，防止任意输入访问真实采集数据。
- Mock登录改为专用开发账号，错误凭据返回统一`AUTH_FAILED`；错误包包含`persistence`，前端能够保留401、409和501等业务错误语义。
- 组合筛选不再静默忽略；LIVE模式无法应用的分析筛选返回`DATA_NOT_READY`，混合帖子评论查询要求明确`contentType`以保证分页稳定。
- Mock总览、主题和关键词无法依据fixture真实重算的筛选同样返回`DATA_NOT_READY`；内容列表要求`POST|COMMENT`二选一，Web默认帖子并分别分页。
- Mock撤销人工修正会恢复保留的模型基线；正式证据必须使用小红书HTTPS域名，模拟证据禁止携带可打开链接。
- 移动内容详情入口、内容分页、1024px导航标签、移动表格提示、未保存修正确认和三类趋势下钻完成体验修复。
- 浏览器标题在接口元信息到达后更新，自动化验收增加标题状态等待，避免把异步更新误判为缺失。
