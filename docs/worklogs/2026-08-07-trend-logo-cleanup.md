# 趋势折线与侧边栏品牌区清理

## 趋势图

负面趋势路径和数据点原先共用同一条样式规则，路径因此继承了风险色填充，覆盖基础的`fill: none`并形成面积色块。本次将路径和标记点拆分：路径只保留风险色描边且明确不填充，标记点继续使用风险色填充。透明点击区域、键盘焦点和数据点联动行为没有变化。

## 品牌区

- 删除侧边栏中的RT方框，只保留RedTrace名称和“小红书舆情监测系统”副标题。
- Red继续使用风险红，Trace保持主文字颜色。
- 侧边栏达到8rem时显示RedTrace名称，达到10rem时再显示副标题，避免紧凑宽度下文字拥挤。
- 侧边栏低于8rem时隐藏整个品牌链接，避免只隐藏文字后仍残留空白点击区和键盘焦点框；移动端底栏继续隐藏整个品牌区。
