# 暗色舆情看板第一批实现日志

日期：2026-08-06

## 实施范围

- 将应用壳统一为暗色监测台，包括品牌区、主导航、数据模式、数据生成时间和退出入口。
- 精修概览页，按“趋势、上升问题、原始证据”的阅读顺序重组首屏。
- 使用现有`OverviewData`字段展示负面数量、负面占比、帖子数、评论数、三类排行和采集健康状态，没有增加推测指标。
- 使用可访问的内联SVG绘制情感趋势折线图，数据点支持鼠标和键盘进入内容库，同时保留完整数据表。
- 区分统计尚未准备、数据依赖不可用、网络异常和合同解析异常，提供继续查看内容库或数据状态的入口。
- 其余页面继承新的暗色色彩、面板、表格、表单、状态和响应式设计系统。

## 关键约束

- 没有改动后端、数据合同或测试。
- 没有引入新的前端依赖，也没有显示接口不支持的同比、覆盖率或重复率等指标。
- 模拟模式仍显示明确提醒，正式模式不显示模拟标识。
- 移动端使用底部导航，概览内容改为单列，错误操作区可以换行。

## 验证

- TypeScript：`npm exec -- tsc -p tsconfig.app.json --noEmit --incremental false`通过。
- 生产构建：`npm exec -- vite build --configLoader runner --outDir .build-verify`通过，临时产物验证后已删除。
- 补充检查：`git diff --check`通过。

## 后续项

- 由主控安排运行时视觉审查和用户流程审查。
- 后续批次逐页精修原因洞察、内容库、品牌监控、数据状态和登录页的专属布局。

## 双审查修正

- 将“上升问题”调整为按证据数量排序的“热门问题”；缺少变化比例时不再显示比较话术。
- 刷新期间保留可读的旧数据，并显示“正在更新”状态与`aria-busy`；刷新失败且仍有旧数据时明确说明其没有按当前筛选更新。
- 修复390px等移动端宽度下内容区仍保留桌面侧栏偏移的问题，并为横向趋势图补充滑动提示。
- 提升第三级文字与暗色面板的对比度。
- 全局筛选复用品牌列表接口，使用品牌名称选择器，同时继续通过URL中的`brandIds`传递筛选条件；列表加载失败和空列表均显示业务化状态。
