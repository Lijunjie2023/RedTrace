# 舆情概览驾驶舱细化实现

日期：2026-08-06

## 前端实现

- 首页首次进入时按照北京时间初始化近7个自然日，并用同一组日期更新URL和首次概览请求。
- 筛选控件使用待查询状态，只有点击“查询”才提交日期、品牌和品类；清除操作只恢复待查询条件。
- 品牌和品类下拉改为受控弹层，同一时间只打开一个，支持点击外部和Escape关闭，选择时保持打开。
- 趋势图移除内部最小宽度和横向滚动；7天显示全部日期，长区间抽样显示标签并保留首尾日期。
- 情感构成在无数据和口径不可用时保留相同卡片位置及灰色环形占位。
- 问题热榜展示排名、问题、较上期、影响帖子和评论，继续支持点击联动右侧原话。
- 首页隐藏全局顶部栏，正式数据状态、数据状态入口和安全退出移动到侧边栏底部；移动端保留紧凑图标入口。
- 首页筛选区使用吸顶布局，层级高于内容卡片且低于侧边导航。
- 驾驶舱沿用现有字体、风险红色和间距变量，补充面板标题、关键指标、正文与移动端卡片内边距层级。

## 2026-08-07 审查修复

- 概览热榜合同兼容滚动发布：影响帖子数和评论数允许暂缺，缺失时前端使用灰色“-”占位。
- 多选下拉改为按组件自身边界判断外部点击，并在外部点击、Escape或切换下拉时关闭和清空搜索词。
- 首页统一维护待查询条件；筛选条和品类卡只编辑同一份草稿，点击“查询”后才提交URL并刷新概览。
- 待查询条件与已应用条件不一致时显示“筛选条件尚未查询”，浏览器前进和后退会重新同步两者。
- 移动端底栏隐藏数据模式与数据状态，只保留四项导航和带文字的安全退出；桌面侧边栏保持三项状态操作。
- 筛选参数错误识别为`VALIDATION_ERROR`，趋势数据点扩大透明点击区域，多选项触控高度统一使用控件高度变量。
