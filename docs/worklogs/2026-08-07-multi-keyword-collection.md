# 多关键词API采集开发记录

## 目标

恢复生产环境的API采集凭证和AI分析凭证保存能力，并让一次采集任务支持多个关键词。

## 关键词规则

- 支持中文逗号和英文逗号分隔。
- 自动去除首尾空格、空项和大小写重复项。
- 每个任务最多包含5个关键词，规范化后的完整字段不超过50个字符。
- 帖子上限按每个关键词计算，每个关键词最多10篇。
- 跨关键词命中的相同帖子只采集一次，同时保存该帖子的全部关键词命中关系。
- 没有评论的帖子仍然不进入业务数据库。

## 凭证配置

- 生产环境当前缺少 `CREDENTIAL_ENCRYPTION_KEY_BASE64`，这是凭证无法保存的直接原因。
- 主密钥必须在生产服务器本地生成并写入受控环境文件，不进入命令输出、仓库或日志。
- 已有代码保持保存和解密时强制要求主密钥。

## 验证

- 多关键词解析、去重、数量限制和采集循环需要加入自动化测试。
- 交付前执行全量测试、类型检查和生产构建。
- 上线后使用不含真实凭证的状态检查确认配置已生效，再由用户在页面保存凭证。
