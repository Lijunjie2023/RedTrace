# JustOneAPI卡萨帝小批量采集与数据库导入

- 日期：2026-08-06
- 关键词：卡萨帝
- 范围：搜索第一页，最多3篇明确命中品牌词的笔记，每篇首批评论
- 数据库采集任务ID：94

## 实现

- 增加JustOneAPI搜索、详情和评论响应到现有`Post`、`Comment`标准结构的映射。
- 只选择标题或正文明确包含“卡萨帝”的搜索结果，避免把泛词搜索结果误记为品牌证据。
- 产出既有导入器要求的`posts.json`、`comments.json`和`report.json`，并继续保留脱敏后的`responses.json`用于字段复核。
- 复用现有`db:import-probe`事务持久化链路，没有新建平行表或直接拼接SQL。
- 扩充API响应脱敏键，覆盖服务Token、`xsec_token`、访问令牌、密码、Cookie和常见授权字段。
