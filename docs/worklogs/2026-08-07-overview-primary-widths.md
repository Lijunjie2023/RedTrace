# 舆情概览顶部三栏宽度调整

## 目标

- 负面问题变化占顶部可用宽度的 40%。
- 问题热榜与代表性原话各占 30%。
- 不影响下方品类内容对比、情感构成和数据质量模块的 12 列布局。

## 实现

- 在概览页为顶部三个面板增加独立的 `overview-primary-row` 容器。
- 桌面端使用 `4fr 3fr 3fr` 三列网格，并为每列设置可收缩的最小宽度，避免产生横向滚动。
- 小于 1024px 时降级为单列，保留现有移动端阅读顺序。
- 数据请求、榜单联动、趋势图钻取和证据展示逻辑均未改动。

## 验证

- 运行前端类型检查。
- 运行前端生产构建。
- 检查 Git 差异，确认未覆盖工作区内其他任务的改动。
