# API采集控制台验收标准

## B1 实体与生命周期

### 采集凭证

- 类型：JustOneAPI Token。
- 生命周期：未配置→已配置→已更新或已删除。
- 数据库存储AES-GCM密文；接口只返回是否配置、末尾4位和更新时间。
- 正在运行的采集任务引用该凭证时，不允许删除。

### 分析凭证

- 类型：DeepSeek API Key。
- 生命周期：未配置→已配置→已更新或已删除。
- 数据库存储AES-GCM密文；接口只返回是否配置、末尾4位和更新时间。
- 正在运行的分析任务引用该凭证时，不允许删除。

### 采集任务

- 生命周期：等待执行→正在采集→采集完成、部分完成或采集失败。
- 用户请求停止时：正在采集→停止中→已停止。
- 停止请求不会中断已经发出的单次API请求，不会回滚已经入库的数据。
- 同一品牌同一时间只允许一个等待执行、正在采集或停止中的任务。

### 采集进度

- 记录API获取帖子数、API获取评论数、入库帖子数、入库评论数、无评论跳过帖子数和失败数。
- 任务列表和任务详情读取持久化进度，刷新页面后继续显示。

## B2 五个必问

- 空状态：未配置JustOneAPI Token时禁止创建任务；未配置DeepSeek密钥时允许采集，采集后不自动分析。
- 失败：鉴权失败立即终止；网络错误和限流有限重试；已写入数据不回滚。
- 引用：凭证只返回配置状态和末尾4位；运行任务存在时禁止删除对应凭证。
- 并发：同一品牌只允许一个活跃采集任务；重复请求返回409。
- 后悔：停止只阻止后续API请求，不撤销已入库数据；重新采集创建新任务并保留历史。

## B3 输入输出链

输入：管理员会话、品牌、关键词、帖子上限、JustOneAPI Token和DeepSeek API Key。

输出：加密凭证、采集任务、进度计数、标准帖子和评论、采集完成后的待分析数据。

依赖：JustOneAPI、MySQL、现有帖子评论持久化服务和DeepSeek自动分析服务。

## B4 第一版范围

必须实现：

1. 凭证配置状态、保存、更新和删除。
2. 创建API采集任务并异步执行。
3. 请求安全停止采集任务。
4. 持久化采集进度并在页面轮询显示。
5. 没有评论的帖子不入库。
6. 采集完成后由现有自动分析机制处理。

延后实现：定时采集、多平台凭证、任务队列横向扩容和跨服务器执行。

## B5 验收标准

### AC-1：安全配置凭证

- 管理员可以分别保存JustOneAPI Token和DeepSeek API Key。
- 数据库只保存AES-256-GCM密文、随机向量、认证标签、末尾4位和更新时间。
- 响应、日志和错误中不得包含密钥原值，只返回`configured`、`lastFour`和`updatedAt`。
- 缺少或不合法的服务端主密钥时，凭证写入和读取返回安全的503错误。

### AC-2：创建采集任务

- 管理员选择已启用品牌，输入1至50个字符的关键词和1至10篇帖子上限后，可以创建任务。
- 未配置JustOneAPI Token时返回422；同品牌已有活跃任务时返回409。
- 接口返回202和持久化任务，服务端异步执行，不占用HTTP请求连接。

### AC-3：采集与入库

- 任务依次执行搜索、帖子详情和评论请求，并复用现有字段标准化及数据库持久化逻辑。
- 没有取得评论的帖子计入`skippedNoCommentPostCount`，不写入业务数据库。
- 任务持续记录`fetchedPostCount`、`fetchedCommentCount`、`storedPostCount`、`storedCommentCount`、`skippedNoCommentPostCount`和`failedCount`。

### AC-4：安全停止

- 对正在执行的任务请求停止后，状态变为`STOPPING`。
- 当前单次API请求完成后不再发起下一次请求，最终状态变为`STOPPED`。
- 已经入库的数据和进度保留；对终态任务再次停止返回422。

### AC-5：任务状态与进度页面

- 数据采集入口展示凭证配置、采集表单、开始与停止按钮、最近任务及六项进度。
- 活跃任务每3秒刷新一次；刷新浏览器后从数据库恢复进度。
- 页面区分等待执行、正在采集、停止中、已停止、完成、部分完成和失败状态。

### AC-6：采集后分析

- 配置DeepSeek密钥时，采集入库内容由现有每30分钟分析任务处理，也可以继续使用手动分析。
- 未配置DeepSeek密钥时采集不失败，页面明确显示待配置分析凭证。

### AC-7：鉴权与审计边界

- 所有凭证和采集控制接口沿用管理员会话鉴权。
- 日志只记录任务ID、状态、计数和安全错误码，不记录帖子正文、评论正文或任何密钥。

### AC-8：迁移与兼容

- 新迁移只新增凭证表和采集任务进度字段，禁止删除或清空现有数据。
- 旧任务映射为原有终态，新增字段默认0；现有数据查询和分析接口保持兼容。
