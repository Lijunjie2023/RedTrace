# 舆情概览驾驶舱细化验收标准

输入方案：`docs/ui-20260806-overview-dashboard-refinement.md`

## AC-1 默认近7天

- 首次进入首页时，开始日期为北京时间今天往前第6天，结束日期为今天。
- 首次概览请求和地址参数使用同一日期范围。
- 日期边界分别为`00:00:00+08:00`和`23:59:59+08:00`。

## AC-2 显式查询

- 修改日期、品牌或品类只更新待查询条件，不调用概览接口。
- 点击“查询”后一次提交全部筛选条件，并清除已选择的问题。
- “清除筛选”恢复近7天、全部品牌、全部品类的待查询条件，不立即请求。
- 浏览器前进或后退后，筛选控件与已应用条件保持一致。

## AC-3 多选下拉

- 同一时间只打开一个品牌或品类下拉。
- 点击控件外部或按Escape关闭下拉。
- 勾选项目、全选或清空时下拉保持打开，方便连续选择。
- 弹层最高750px，并且不超出当前视口；选项区域内部滚动。

## AC-4 趋势日期与响应式

- 概览接口按已选日期返回完整自然日序列，没有数据的日期补零。
- 趋势图显示已应用日期范围，近7天显示全部日期标签；更长范围抽样标签并保留首尾日期。
- 320px到2560px宽度内，趋势图内部没有横向滚动条。
- 数据点继续支持鼠标和键盘进入对应日期的负面内容。

## AC-5 情感构成空状态

- 有数据、无数据和口径不可用时，情感卡片占用相同网格位置和基本高度。
- 无数据时显示灰色环形图、“暂无数据”和当前筛选无可用内容的提示，不显示虚构比例。

## AC-6 问题热榜

- 每行显示排名、问题、较上期、影响帖子和评论，并垂直居中。
- 影响帖子按不同帖子去重；仅评论命中问题时，其所属帖子也计入。
- 评论数只统计直接命中问题的评论。
- 上期为与当前周期等长、紧邻当前周期之前的日期范围。
- 上期为零或无法比较时，接口返回`null`，前端显示灰色“-”。
- 点击问题继续联动右侧代表性原话。

## AC-7 首页信息收敛

- 首页不显示“查看负面内容”和“查看趋势数据表”。
- 首页隐藏顶部Header；其他页面保留Header。
- 首页的正式数据状态和安全退出移动到侧边栏底部。
- 首页筛选区固定在内容顶部，滚动时保持可见，不遮挡内容或下拉弹层。

## AC-8 驾驶舱字体层级

- 保留现有字体家族与红色风险语义。
- 面板标题、关键指标、正文、表头、辅助信息按UI方案中的字号和行高执行。
- 1366px桌面和移动端均不截断关键操作文字，不引入页面级横向滚动。

## AC-9 工程验证

- 合同测试覆盖新增热榜字段。
- MySQL概览测试覆盖日期补零、帖子去重、评论数和上期变化。
- `npm test`、`npm run typecheck`和`npm run build`通过。
