# DeepSeek分析边界决策

## 决策

第一版采用“离线批处理分析，页面只读已落库结果”的边界，不在用户打开页面时同步调用DeepSeek。

模型原始结果、人工修正和页面有效结果分开处理：模型结果保留历史版本；人工修正独立存储；查询时优先返回人工修正，否则返回最新成功模型结果。

## 原因

- 页面请求不承担模型延迟、限流和余额异常，界面响应更稳定。
- 重复打开页面不会重复计费。
- 每个结论都能对应确定的内容版本、模型版本、提示词版本和词表版本。
- 模型更新或词表调整后可以重新分析，同时保留旧结果以便比较。

## 约束

- 只有批处理服务能够调用DeepSeek。
- API密钥只存在于运行环境中。
- 页面和普通API日志不得记录完整模型请求与响应。
- 自动分析失败时保留最近一次成功结果和全部原始证据。
