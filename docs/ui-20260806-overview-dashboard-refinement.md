# 舆情概览驾驶舱细化方案（待确认）

## 目标

在不改变现有深色风险驾驶舱方向的前提下，修正筛选、趋势、空状态和热榜的数据表达。首页保持三栏主布局，并在常见桌面分辨率下减少无效留白和过大的文字。

## 页面结构

1. 首页不再显示顶部 Header。筛选区成为首页内容区的第一层，滚动时固定在顶部。
2. 第一行保持三栏：负面问题变化 6/12，问题热榜 3/12，代表性原话 3/12。
3. 第二行保持品类对比 9/12，情感构成 3/12。
4. 1023px 以下改为单栏，筛选区仍固定，但不遮挡内容。

## 筛选区

- 首次进入首页时，开始时间为今天往前第 6 天的 00:00:00，结束时间为今天的 23:59:59，使用 Asia/Shanghai 自然日。
- 控件编辑值与已查询值分离。编辑日期、品牌、品类时不请求数据；点击“查询”后一次提交，并清除当前问题联动状态。
- “清除筛选”恢复“近 7 天、全部品牌、全部品类”的待查询状态，不立即请求数据；点击“查询”后生效。
- 品牌和品类下拉采用受控开关。同一时间只允许打开一个；点击控件外部或按 Escape 关闭。
- 选择项目后下拉不立即关闭，便于多选；点击外部关闭。弹层最高 750px，同时不能超过当前视口可用高度，选项列表内部滚动。
- 筛选区固定后使用不透明深色背景和底部分隔线，层级高于内容卡片、低于下拉弹层。

## 负面问题变化

- 横轴严格使用当前已查询的日期范围。后端补齐范围内没有数据的日期，值为 0。
- 图表不设置最小宽度，不出现横向滚动条。折线始终适应容器宽度。
- 近 7 天显示全部日期；更长范围保留全部数据点，只抽样显示日期标签，并固定显示首尾日期。
- 隐藏“查看负面内容”和“查看趋势数据表”。数据点点击、回车和空格键进入对应日期的负面内容。

## 情感构成空状态

- 有结果、无结果和口径不可用三种状态使用同一张卡片和同一套网格尺寸。
- 无结果时保留环形图尺寸，环形图整体置灰；中央显示“暂无数据”，下方显示“当前筛选范围内没有可用内容”。
- 不显示虚构百分比和虚构数量。

## 问题热榜

- 表头：排名、问题、较上期、影响帖子、评论。
- 行内容垂直居中，问题名称只占一行并允许省略；整行仍可点击，联动右侧代表性原话。
- 较上期没有可比较数据时显示灰色“-”。
- “影响帖子”建议定义为命中该问题的不同帖子数，包括问题出现在评论中时所属的帖子；“评论”是直接命中该问题的评论数。
- 上期使用与当前筛选等长、紧邻当前日期之前的周期。上期为 0 时不计算增长率。
- 去掉趋势数据表入口。

## 字号和间距

设计方向为紧凑、克制、专业的深色数据驾驶舱。保留现有字体家族和红色风险语义，不引入新的字体资源。

| 层级 | 桌面字号 | 行高 | 用途 |
| --- | ---: | ---: | --- |
| 面板标题 | 18px | 26px | 负面问题变化、问题热榜等 |
| 关键指标 | 22px | 28px | 数量、比例、增长率 |
| 主要正文 | 14px | 22px | 问题名、代表性原话 |
| 表头与控件 | 13px | 20px | 筛选标签、热榜列头 |
| 辅助说明 | 12px | 18px | 时间轴、说明、状态 |

- 1366px 以下面板标题降为 17px，主要正文保持 14px。
- 不全局放大字号；通过标题、指标、正文、辅助信息的固定层级减少当前页面的大小竞争。
- 卡片内边距桌面 16px，三栏间距 12px；小屏内边距 14px。

## 后端数据要求

- 现有 `/overview` 继续接收 `from`、`to`、`brandIds`、`categoryIds`，不新增重复端点。
- `sentimentTrend` 在已选日期范围内补齐零值日期，最大查询跨度建议限制为 366 天。
- `risingTopics` 增加 `affectedPostCount` 和 `commentCount`，并返回真实的 `changeRatio`。
- 当前周期和上一周期应通过一次聚合查询完成，避免给 1 核 RDS 增加逐行查询。

## 验收标准

- 首次进入首页时日期控件、地址参数和第一次接口请求均为近 7 个自然日。
- 调整任意筛选项不会发起 overview 请求；点击“查询”只发起一次请求。
- 下拉点击外部和 Escape 可以关闭，最高不超过 750px，小屏不超出视口。
- 320px 到 2560px 宽度内，趋势图内部没有横向滚动条。
- 无情感数据时第二行布局不变化，灰色环形图和提示正常显示。
- 热榜每行显示真实的较上期、影响帖子和评论数据；没有上期数据时显示灰色“-”。
- 首页滚动时筛选区固定，且不会被下拉层或移动端导航遮挡。
- 首页不显示“查看负面内容”和“查看趋势数据表”。

## 待确认

2. “影响帖子”建议按不同帖子去重，包含仅在评论中命中问题时所属的帖子。
