# 项目错误记录

## 2026-08-06：Workbench 多行粘贴预览暴露数据库凭据

- 严重程度：严重。
- 现象：通过 Workbench 终端关闭回显后粘贴 `.env.local` 时，Workbench 在终端之外弹出多行粘贴预览框；随后读取页面状态时，一部分数据库凭据进入了受控操作回显。
- 影响：远端配置文件未写入，文件保持为空；已取消预览并清空浏览器剪贴板。已经暴露的数据库应用账号密码必须轮换后才能继续部署。
- 根本原因：只考虑了终端回显和 Shell 历史，没有把 Workbench 自带的多行粘贴确认界面纳入数据暴露边界。
- 强制规则：禁止通过终端多行粘贴、命令行参数、Shell 历史、页面预览或聊天内容传输密钥、密码、Cookie、Token 和完整环境文件。
- 后续做法：秘密配置只能通过不会显示文件正文的文件上传、受控秘密管理服务或用户在服务器端的隐藏输入流程传递。任何上传控件失效时必须停止并请求用户恢复安全传输通道，不能改用多行粘贴绕过。
